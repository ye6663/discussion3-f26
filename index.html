Discussion #3 Assignment

Introduction

To complete this assignment, follow the instructions on this page (open it with LiveServer!).

Step 1: Styling the Background

Change the background color of this site to a color you like.

Step 2: Styling Text

  1. Change the font of all the p elements to Helvetica.
  2. Make all h2 elements bold and 30px.
  3. Change the color of one text element (you can choose) to a different color.

Step 3: Styling images

  • Make all of the images 300px wide.
  • Put a 5px solid border around your images in the color #4f4cf7.

Step 4: Other Styles

  1. Change the background of this div to a color youdon'tlike.
  2. Change the bullet points in unordered lists to be squares.

Step 5: Validate

Make sure to validate your page using the following elements!

  • Wave
  • aXe
  • W3
  • Console

Step 6: Submit!

Submit the link to your Github Repo to the Discussion #3 Assignment. Make sure you uploaded your edited code and deployed your GitHub Page.
